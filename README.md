# 夸克扫描导出工具

把夸克浏览器扫描生成的临时文件导出到相册（或任意指定目录）的 Android 小工具。

夸克的扫描件先落在它自己的私有临时目录里，系统相册看不到、也没法直接分享。本工具读取那个目录，把扫描件按真实格式（JPEG / PNG / PDF 等，按文件头判断）导出到指定位置，并可选地在导出后清空源目录。

---

## 功能

- **扫描**：列出夸克临时目录里可导出的扫描件，显示数量、大小与类型
- **导出**：勾选后导出到指定目录（默认 `/storage/emulated/0/Pictures`），去临时后缀、写回真实扩展名
- **可选清理**：导出后清空夸克临时目录（默认开，可关，状态持久化）
- **预览**：复制到本应用的可共享目录后交给系统查看器 / 对应应用打开
- **已导出标记**：目标目录里已存在的文件自动标记，避免重复导出
- **日志导出**：应用内日志 + 环境信息（版本 / 系统 / 机型 / 权限状态），便于排查问题
- **扫描完成提醒**：开启后，当夸克生成新的临时文件、并且被从最近任务移除时，自动发送通知提示有新扫描件

## 环境要求

| 项 | 要求 |
|---|---|
| Android | **7.0（API 24）及以上** |
| 提权方式 | **Shizuku**（默认，需自行安装并启动）或 **Root**（KernelSU / Magisk）|
| 夸克浏览器 | 需要，本工具读取的是它自己的扫描缓存目录 |

> 最低版本由 Shizuku API 库决定：该库声明 `minSdk 24`，因此使用它的应用无法支持 Android 6。

## 权限说明

应用只声明 4 个权限：

| 权限 | 用途 |
|---|---|
| `FOREGROUND_SERVICE` | 后台监视夸克扫描（前台服务）|
| `FOREGROUND_SERVICE_SPECIAL_USE` | 同上，前台服务类型声明 |
| `POST_NOTIFICATIONS` | 扫描完成提醒 |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | 让后台监视不被系统冻结（由系统弹窗确认）|

**应用没有声明 `INTERNET` 权限** —— 不联网、不上传任何数据，全部操作在本机完成。读写夸克私有目录所需的高权限由 Shizuku 或 Root 在运行时提供。

## 使用

首次打开会显示一份待办清单，按顺序完成即可（清单全部完成后自动消失）：

1. **完成文件访问授权** —— Shizuku 或 Root
2. **允许本应用发送通知**
3. **允许本应用后台运行** —— 省电策略设为「无限制」
4. **打开「扫描完成提醒」的悬浮通知与声音** —— 小米等系统默认可能是关的

之后的主流程：**扫描 → 勾选文件 → 导出**。

### 关于后台提醒

- Android 8.0 起，持续的后台工作只能由**前台服务**承担，而前台服务**必须挂一条通知**。因此那条「扫描监视」通知是合法后台工作的**门票**，不是提醒本身。
- 在系统通知设置里关掉「扫描监视」，只是让那条常驻通知不再显示，**监视与提醒照常工作**。
- 「扫描完成提醒」通道建议在系统里打开**悬浮通知**与**声音**，否则提醒可能不会弹横幅（这类通道级开关应用无法代替系统设置）。

## 构建

```sh
# Android Studio 自带的 JBR 即可（AGP 9 需要 JDK 17+）
export JAVA_HOME="/path/to/jdk"

sh gradlew :app:assembleDebug      # 调试包
sh gradlew :app:assembleRelease    # 正式包
```

正式包需要签名配置：

```sh
cp keystore.properties.example keystore.properties   # 然后填入自己的密钥信息
```

缺少 `keystore.properties` 时仍可正常构建 debug 包；release 会产出未签名的 APK（无法安装）。

## 已知限制

- 依赖夸克自身的私有目录结构与临时文件命名，**夸克版本更新后可能失效**
- 需要设备具备 Shizuku 或 Root，未授权的设备无法使用
- 应用只处理夸克标记为扫描产物的会话目录，其它缓存不参与导出
- 后台提醒的触发时机是「夸克被移出最近任务」；夸克自身退出但进程仍在时不会误报
